# Contributing to Mine

**Mine** is a personal project. Contributions are welcome if you are collaborating on this repo.

## Setup

```bash
git clone <your-fork-url>
cd mine
npm install
npm run dev
```

## Code quality

```bash
npm run check
npm run check:fix
```

## Guidelines

- Keep changes focused and incremental.
- Match existing patterns in `src/routes/` (colocation-based architecture).
- Update `src/config/app-config.ts` for global branding changes.
